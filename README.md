# Prism — EU AI Act Compliance Engine

Upload an AI system description. Get a structured, evidence-grounded 12-section compliance report in under 90 seconds.

---

## What it does

Prism takes a PDF, DOCX, or plain-text description of an AI system and produces a complete EU AI Act assessment: risk classification, prohibited-practice check, applicable obligations, provider/deployer role determination, governance gaps, and a confidence score — all with cited evidence and a full agent trace.

---

## Architecture

### Five-agent pipeline with typed signals

Each agent has a single responsibility and communicates only through **typed signals** — not shared mutable state.

| Agent | Responsibility |
|---|---|
| **Extraction** | Parses the document into structured facts (industry, AI capabilities, automation level, affected persons, GPAI components) |
| **Retrieval** | Hybrid BM25 + semantic search (RRF merge) over the EU AI Act corpus — pre-computed document vectors, only the query is embedded at runtime |
| **Analysis** | Six legal dimensions assessed in **parallel** (`ThreadPoolExecutor`) — each dimension independently retrieves, reasons, and produces labelled claims |
| **Validation** | Challenges weak claims against authoritative chunks; parallel for claims with sufficient evidence, sequential for those needing fresh retrieval |
| **Synthesis** | Merges findings into the final 12-section report; claims and citations are **injected programmatically** (not LLM-generated) to eliminate hallucination in structured output |

### Orchestrator loop with rollback

The orchestrator drives the pipeline through a signal protocol:

- `RetrievalSignal` → fetch more chunks, retry the dimension
- `LoopSignal` → roll back to post-analysis checkpoint, re-run validation + synthesis
- `CompletionSignal` → finalise report

Checkpoints are immutable snapshots (`copy.deepcopy`). No agent can corrupt a prior stage's state.

### LLM detach / reattach (live resilience)

The LLM client wraps every call in a retry loop. On any connection error:
- Sets a `threading.Event` (`_llm_connected.clear()`)
- Sleeps 5 s and retries — **indefinitely**
- The job status changes to `waiting_llm`; the UI shows a yellow "paused" state
- When the LLM returns, the pipeline resumes exactly where it was — no data loss, no re-submission

### Sections 11 & 12 are programmatic, not LLM-generated

- **§11 Evidence separation** — all claims across all dimensions are grouped by epistemological label (`FACT / RETRIEVED / ASSUMPTION / UNCERTAIN`) from the pipeline state, not from the LLM
- **§12 Agent trace** — a structured timeline of every stage's inputs and outputs, built from real pipeline state

This means these sections cannot hallucinate.

### Confidence score computed, not prompted

`overall` confidence = `min(all 6 dimension scores)`. The LLM's opinion is discarded. Most conservative reading wins — correct for compliance contexts.

## Stack

- **Backend** — Python, FastAPI, `uvicorn`; pipeline runs in a `ThreadPoolExecutor`
- **LLM** — OpenAI-compatible local inference (Qwen 3.6B-27B via vLLM)
- **Embeddings** — `BAAI/bge-m3` (DataCrunch hosted)
- **Retrieval** — Okapi BM25 + cosine semantic, fused with Reciprocal Rank Fusion
- **Corpus** — 48 hand-authored atomic nodes covering Articles 3, 5, 6, 9–17, 25–26, 50 and Annex I/III
- **Frontend** — Next.js 14, Tailwind CSS; text or file input; real-time pipeline status; full 12-section collapsible report
- **Job persistence** — disk-backed JSON (`logs/jobs/<id>.json`); in-flight jobs survive server restarts

## Running locally

```bash
# 1. Backend
pip install -r requirements.txt
uvicorn api.server:app --port 8001 --reload

# 2. Frontend
cd web && npm install && npm run dev
# → http://localhost:3000
```

**Environment variables** (`.env` or shell):

```
LLM_BASE_URL=http://localhost:8000/v1
LLM_MODEL=Qwen/Qwen3.6-27B
EMBED_BASE_URL=https://...
EMBED_MODEL=BAAI/bge-m3
EMBED_API_KEY=<token>
```

## Report structure

| § | Section | Generated by |
|---|---|---|
| 1 | Use-case summary | LLM |
| 2 | Extracted facts | LLM |
| 3 | AI system determination (Art. 3) | LLM |
| 4 | Risk classification (Art. 6, Annex III) | LLM |
| 5 | Prohibited practices check (Art. 5) | LLM |
| 6 | Transparency / GPAI obligations (Art. 50, 52–55) | LLM |
| 7 | Provider / deployer roles (Art. 25–26) | LLM |
| 8 | Governance obligations (Arts. 9–17, 62) | LLM |
| 9 | Missing information & recommended actions | LLM |
| 10 | Confidence score (per-dimension + overall) | LLM dims, overall = min() |
| 11 | Evidence separation (FACT / RETRIEVED / ASSUMPTION / UNCERTAIN) | **Programmatic** |
| 12 | Agent trace (stage-by-stage timeline) | **Programmatic** |
